usage: mailctl filter [-h] [--verbose] [--debug] [--provider PROVIDER]
                      [--env-file [PATH]]
                      {list,add,apply,remove,move,rename,enable,disable,optimize} ...

Save filters, and apply them to mail already delivered.

positional arguments:
  {list,add,apply,remove,move,rename,enable,disable,optimize}
    list                show the filters in order, and which cannot fire
    add                 save a filter; mail already delivered is left alone
    apply               act on mail already delivered
    remove              remove a named filter from the active filter set
    move                move a named filter to a new position, unchanged
    rename              give a named filter a new name, unchanged otherwise
    enable              enable a named filter, keeping it in the filter set
    disable             disable a named filter, keeping it in the filter set
    optimize            propose a better order for the filters, and merge
                        duplicates

options:
  -h, --help            show this help message and exit
  --verbose, -v         step-by-step progress
  --debug               show a full traceback on failure (never prints
                        credentials)
  --provider PROVIDER   the mail host, by provider name; default mxroute
  --env-file [PATH]     read MAILCTL_* settings from a dotenv-style file
                        (default .env in the current directory); before the
                        command, give the PATH
